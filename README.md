# NEXUS — личный оперативный центр

Открой `index.html` в браузере. Никакой установки или аккаунта не требуется.

Внутри уже есть:

- тёмная шпионская эстетика с золотыми акцентами;
- недельный календарь: задачи можно добавлять, редактировать, удалять и перетаскивать по дням и времени;
- баланс, доходы и расходы с категориями;
- журнал тренировок с недельной целью;
- проекты с описанием и цветовой меткой; задачу можно привязать к проекту;
- раздел «Все данные»: редактирование и удаление любых задач, операций, тренировок и проектов;
- изменение и сброс начального баланса; счётчики задач и тренировок обновляются по записям автоматически;
- отдельные профили пользователей: имя, валюта и недельная цель тренировок; у каждого профиля свои записи;
- быстрые формы и адаптация для телефона. На телефоне дату и время задачи можно поменять в её карточке.

При первом открытии настрой профиль. Создавай и переключай профили через блок пользователя внизу бокового меню. Новый профиль начинается с чистого пространства.

Данные сохраняются в браузере на устройстве и не синхронизируются между устройствами. Если поделиться страницей или разместить её на статическом хостинге, каждый посетитель получит отдельное хранилище в своём браузере. Для аккаунтов с облачной синхронизацией понадобится сервер.
